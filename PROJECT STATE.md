## What This Project Is

This project develops the theory of the Nested Semantic Graph — a language-neutral representation of meaning as an ultrametric tree of conceptual primitives. The core claim is that all human languages linearize the same underlying nested structure, and that recognizing this structure enables sub-graph matching search across the full morphological spectrum (isolating to polysynthetic). The project bridges the user's well-developed ultrametric physics corpus with computational linguistics.
