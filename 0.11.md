# 0.11 — NST Visualization Tool

**Version:** 0.11
**Date:** 2026-05-22
**Status:** Complete — Sprint 4.1 deliverable

## Summary

Built an interactive HTML/JS viewer for Nested Semantic Trees. Embedded tree data from 0.9.py's 12-document, 5-language corpus. Supports expand/collapse, node selection for LCA highlighting, and ultrametric distance display.

## Features

| Feature | Implementation |
|:--------|:---------------|
| **Tree selector** | Sidebar with 12 trees grouped by language (English, Turkish, Mohawk, Finnish, Inuktitut) |
| **Expand/collapse** | Click any non-leaf node to collapse its subtree. Click again to expand |
| **LCA highlighting** | Click two nodes to select A (yellow) and B (green). LCA highlighted with pink dashed circle. Paths traced in colored dashed lines |
| **Distance display** | Status panel shows ultrametric distance d(A,B) = height(LCA(A,B)) |
| **Node color coding** | SENTENCE=indigo, VERB=red, SUBJ=amber, OBJ=blue, ADJUNCT=purple, TENSE=pink, CASE=teal, LEAF=green |
| **Language badges** | Color-coded badges (en=green, tr=blue, mh=purple, fi=indigo, ik=orange) |
| **Legend** | Visual legend for selection colors |

## Technical

- **Single file:** `0.11.html` (29,351 bytes) — zero dependencies, no CDN
- **Rendering:** Inline SVG with recursive tree layout
- **Data:** 12 trees embedded as JSON (12,322 bytes)
- **LCA:** O(depth) path-intersection algorithm
- **Layout:** Proportional leaf-count width allocation, 70px level height
